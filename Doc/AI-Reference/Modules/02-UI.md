# GF_X 模块参考：UI（界面系统）

> 本文档帮助 AI 理解并正确使用 GF_X 的 UI 管理系统。

---

## 1. 核心概念

### 1.1 UI 系统架构

```
┌─────────────────────────────────────────────────────────┐
│                    UI 系统 (UIManager)                   │
├─────────────────────────────────────────────────────────┤
│  UIGroup (UI组/层级)                                     │
│  ├── Builtin (内置弹窗层)                                │
│  ├── Dialog (对话框层)                                   │
│  ├── Guide (引导层)                                      │
│  ├── Main (主界面层)                                     │
│  ├── Menu (菜单层)                                       │
│  ├── Notify (通知层)                                     │
│  └── Top (顶层/屏蔽层)                                   │
├─────────────────────────────────────────────────────────┤
│  UIForm (界面实例)                                       │
│  ├── UIFormLogic (界面逻辑脚本)                          │
│  └── 预制体 (UI Prefab)                                 │
└─────────────────────────────────────────────────────────┘
```

### 1.2 关键术语

| 术语 | 说明 | 类比 |
|------|------|------|
| **UIGroup** | UI 层级/组，控制显示顺序 | Photoshop 的图层组 |
| **UIForm** | UI 界面实例 | 一个打开的窗口 |
| **UIFormLogic** | UI 逻辑脚本 | 窗口的 Controller |
| **UIFormId** | UI 唯一标识 | 窗口的身份证号 |

## 2. 基础使用

### 2.1 打开 UI 界面

```csharp
// 基本用法 - 打开 UI
GF.UI.OpenUIForm(UIFormId.MainMenu);

// 带参数打开 - 传递数据
var data = new MenuData { Level = 5, Score = 1000 };
GF.UI.OpenUIForm(UIFormId.LevelInfo, data);

// 指定 UI 组 (层级)
GF.UI.OpenUIForm(UIFormId.Dialog, null, "Dialog");

// 监听打开成功事件
GF.Event.Subscribe(OpenUIFormSuccessEventArgs.EventId, OnOpenSuccess);
```

### 2.2 关闭 UI 界面

```csharp
// 关闭指定 UI 实例
GF.UI.CloseUIForm(uiFormInstance);

// 在 UIFormLogic 内部关闭自己
Close();

// 关闭指定 ID 的所有 UI
GF.UI.CloseAllLoadedUIForms(UIFormId.Dialog);

// 关闭指定组的所有 UI
GF.UI.CloseAllLoadedUIForms("Dialog");

// 关闭所有 UI
GF.UI.CloseAllLoadedUIForms();
```

### 2.3 创建新 UI 界面（完整流程）

#### 步骤 1: 定义 UIFormId

```csharp
// 文件：Assets/AAAGame/Scripts/Definition/UIFormId.cs

/// <summary>
/// UI 界面 ID 定义
/// </summary>
public static class UIFormId
{
    public const int MainMenu = 1001;
    public const int Setting = 1002;
    public const int LevelSelect = 1003;
    public const int GameHud = 1004;
    public const int Pause = 1005;
    public const int GameOver = 1006;
    public const int Dialog = 2001;     // 通用对话框
    public const int Loading = 9001;    // 加载界面
}
```

#### 步骤 2: 创建 UI 预制体

```
1. 在 Unity 中：GameObject → UI → Canvas (或复制现有 UI)
2. 设计 UI 布局 (Button, Text, Image 等)
3. 将 Canvas 保存为 Prefab：Assets/AAAGame/Prefabs/UI/MyUIForm.prefab
4. 确保 Canvas 上挂载了 UIFormLogic 脚本 (或其子类)
```

#### 步骤 3: 编写 UI 逻辑脚本

```csharp
// 文件：Assets/AAAGame/Scripts/UI/MyUIFormLogic.cs

using UnityGameFramework.Runtime;
using UnityEngine;
using UnityEngine.UI;

/// <summary>
/// 我的 UI 界面逻辑
/// </summary>
public class MyUIFormLogic : UIFormLogic
{
    // ========== 序列化字段 (在 Inspector 中绑定) ==========
    
    [SerializeField]
    private Button _confirmButton;
    
    [SerializeField]
    private Button _closeButton;
    
    [SerializeField]
    private Text _titleText;
    
    [SerializeField]
    private Text _contentText;
    
    // ========== 私有字段 ==========
    
    private MyUIFormData _data;
    
    // ========== 生命周期方法 ==========
    
    /// <summary>
    /// 初始化 (仅调用一次)
    /// </summary>
    protected override void OnInit(object userData)
    {
        base.OnInit(userData);
        
        // 绑定按钮点击事件
        if (_confirmButton != null)
        {
            _confirmButton.onClick.AddListener(OnConfirmClicked);
        }
        
        if (_closeButton != null)
        {
            _closeButton.onClick.AddListener(OnCloseClicked);
        }
    }
    
    /// <summary>
    /// 界面打开时调用
    /// </summary>
    protected override void OnOpen(object userData)
    {
        base.OnOpen(userData);
        
        // 接收并存储数据
        _data = userData as MyUIFormData;
        if (_data == null)
        {
            Log.Warning($"UI {gameObject.name} 没有接收到有效数据");
            return;
        }
        
        // 更新 UI 显示
        UpdateUI();
        
        // 播放打开动画 (如果有)
        PlayOpenAnimation();
    }
    
    /// <summary>
    /// 界面关闭时调用
    /// </summary>
    protected override void OnClose(bool isShutdown, object userData)
    {
        base.OnClose(isShutdown, userData);
        
        // 播放关闭动画
        PlayCloseAnimation();
        
        // 清理数据引用
        _data = null;
    }
    
    /// <summary>
    /// 每帧更新
    /// </summary>
    protected override void OnUpdate(float elapseSeconds, float realElapseSeconds)
    {
        base.OnUpdate(elapseSeconds, realElapseSeconds);
        
        // 处理需要每帧更新的逻辑
        // 例如：倒计时、动画状态检查等
    }
    
    // ========== 私有方法 ==========
    
    /// <summary>
    /// 更新 UI 显示
    /// </summary>
    private void UpdateUI()
    {
        if (_titleText != null && !string.IsNullOrEmpty(_data.Title))
        {
            _titleText.text = _data.Title;
        }
        
        if (_contentText != null && !string.IsNullOrEmpty(_data.Content))
        {
            _contentText.text = _data.Content;
        }
        
        // 根据数据更新其他 UI 元素
    }
    
    /// <summary>
    /// 播放打开动画
    /// </summary>
    private void PlayOpenAnimation()
    {
        // 实现打开动画
        // 例如：淡入、缩放、滑入等
    }
    
    /// <summary>
    /// 播放关闭动画
    /// </summary>
    private void PlayCloseAnimation()
    {
        // 实现关闭动画
    }
    
    /// <summary>
    /// 确认按钮点击处理
    /// </summary>
    private void OnConfirmClicked()
    {
        // 触发确认事件
        var eventArgs = ReferencePool.Acquire<ConfirmUIEventArgs>();
        eventArgs.Fill(_data);
        GF.Event.Fire(this, eventArgs);
        
        // 关闭界面
        Close();
    }
    
    /// <summary>
    /// 关闭按钮点击处理
    /// </summary>
    private void OnCloseClicked()
    {
        // 触发取消事件（如果需要）
        
        // 关闭界面
        Close();
    }
}

/// <summary>
/// UI 数据类
/// </summary>
public class MyUIFormData
{
    public string Title { get; set; }
    public string Content { get; set; }
    public int ConfirmId { get; set; }
    public System.Action OnConfirm { get; set; }
}

/// <summary>
/// 确认事件参数
/// </summary>
public class ConfirmUIEventArgs : GameEventArgs
{
    public static readonly int EventId = typeof(ConfirmUIEventArgs).GetHashCode();
    
    public override int Id => EventId;
    
    public MyUIFormData Data { get; private set; }
    
    public ConfirmUIEventArgs Fill(MyUIFormData data)
    {
        Data = data;
        return this;
    }
    
    public override void Clear()
    {
        Data = null;
    }
}
```

## 5. 常见 AI 错误与纠正

### 5.1 错误：直接 Instantiate UI

```csharp
// ❌ 错误：不要直接实例化 UI
void OpenMenu()
{
    var menu = Instantiate(menuPrefab);
    menu.transform.SetParent(canvas.transform, false);
}

// ✅ 正确：使用 GF.UI 系统
void OpenMenu()
{
    GF.UI.OpenUIForm(UIFormId.MainMenu);
}
```

### 5.2 错误：在 UI 中直接使用 GameObject.Find

```csharp
// ❌ 错误：避免使用 Find，应该在 Inspector 中绑定
void Start()
{
    var button = GameObject.Find("ConfirmButton").GetComponent<Button>();
    button.onClick.AddListener(OnClick);
}

// ✅ 正确：使用序列化字段在 Inspector 中绑定
[SerializeField]
private Button _confirmButton;

protected override void OnInit(object userData)
{
    base.OnInit(userData);
    _confirmButton.onClick.AddListener(OnClick);
}
```

### 5.3 错误：忘记在 OnLeave 中清理

```csharp
// ❌ 错误：没有清理事件订阅
protected override void OnLeave(IFsm<IProcedureManager> procedureOwner, bool isShutdown)
{
    base.OnLeave(procedureOwner, isShutdown);
    // 没有取消事件订阅！
}

// ✅ 正确：清理所有资源
protected override void OnLeave(IFsm<IProcedureManager> procedureOwner, bool isShutdown)
{
    base.OnLeave(procedureOwner, isShutdown);
    
    // 取消事件订阅
    GF.Event.Unsubscribe(...);
    
    // 关闭所有UI
    GF.UI.CloseAllLoadedUIForms();
    
    // 停止音效
    GF.Sound.StopAllLoadedSounds();
}
```

## 6. 快速参考

### 6.1 常用方法速查表

| 操作 | 代码示例 |
|------|----------|
| **切换流程** | `ChangeState<NextProcedure>(procedureOwner);` |
| **打开UI** | `GF.UI.OpenUIForm(UIFormId.MainMenu, data, "Main");` |
| **关闭UI** | `GF.UI.CloseUIForm(uiForm);` 或 `Close();` |
| **显示实体** | `GF.Entity.ShowEntity(typeof(PlayerEntity), data);` |
| **隐藏实体** | `GF.Entity.HideEntity(entityLogic);` |
| **加载资源** | `GF.Resource.LoadAsset<T>(assetName, callback);` |
| **播放音效** | `GF.Sound.PlaySound(SoundId.BgmMenu);` |
| **获取数据表** | `GF.DataTable.GetDataTable<DRItem>();` |
| **获取配置** | `GF.Config.GetString("Game.Name");` |

### 6.2 生命周期顺序

```
Procedure 生命周期:
OnInit() → OnEnter() → [OnUpdate() × N] → OnLeave() → OnDestroy()

UIFormLogic 生命周期:
OnInit() → OnOpen() → [OnUpdate() × N] → OnClose()

EntityLogic 生命周期:
OnInit() → OnShow() → [OnUpdate() × N] → OnHide()
```

---

> 💡 **AI 编码提示**: 使用 Procedure 系统时，始终遵循"状态机思维"：
> 1. 每个 Procedure 是一个独立的状态
> 2. 使用 `ChangeState<>()` 进行状态转移
> 3. 在 `OnLeave` 中清理，避免副作用
> 4. 不要在 `OnUpdate` 中做耗时操作
