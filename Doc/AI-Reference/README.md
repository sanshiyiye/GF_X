## 🚀 快速开始

### 首次使用

1. **阅读框架总览** - `AI-Framework-Overview.md`
   - 理解核心概念和架构
   - 掌握命名规范和代码组织

2. **查看模块详解** - `Modules/*.md`
   - 根据开发需求查阅对应模块
   - 每个模块包含：概念、用法、示例、错误纠正

3. **使用代码模板** - `Templates/*.md`
   - 创建新文件时复制模板
   - 替换占位符，添加业务逻辑

4. **避免常见错误** - `AI-Common-Mistakes.md`
   - 编码前阅读错误清单
   - 编码后对照检查清单

### 开发流程

```
1. 需求分析
   ↓ 确定使用哪些模块
2. 查阅模块文档
   ↓ 理解用法和示例
3. 复制代码模板
   ↓ 填充业务逻辑
4. 编码实现
   ↓ 遵循规范和模式
5. 检查常见错误
   ↓ 对照清单检查
6. 完成
```

## 🎯 使用建议

### 对于 AI 模型

1. **生成代码前**
   - 确定需要使用的模块
   - 查阅对应模块文档
   - 复制代码模板

2. **生成代码时**
   - 遵循文档中的命名规范
   - 使用文档中的 API 调用方式
   - 遵循数据驱动原则

3. **生成代码后**
   - 对照常见错误清单检查
   - 确保事件订阅有取消
   - 确保资源有释放

### 对于开发者

1. **首次使用框架**
   - 完整阅读框架总览
   - 按顺序阅读核心模块
   - 从模板开始实践

2. **日常开发**
   - 遇到问题查阅模块文档
   - 创建新文件使用模板
   - 定期回顾常见错误

3. **代码审查**
   - 使用常见错误清单检查
   - 确保遵循框架规范
   - 检查生命周期管理
