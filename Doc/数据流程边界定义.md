## 二、三类数据的差异化处理

### 2.1 DataTable (数据表)

```
输入: AAAGameData/DataTables/*.xlsx
      (支持子目录, 如 Core/*.xlsx)

处理: RefreshAllDataTable()
      ├─ Excel2TxtFile() → .txt (Tab分隔, 调试可读)
      ├─ GenerateDataFile() → .bytes (二进制, 运行时)
      └─ GenerateCodeFile() → .cs (C#类, 强类型访问)

输出: 
      Assets/AAAGame/DataTable/*.txt
      Assets/AAAGame/DataTable/*.bytes
      Assets/AAAGame/Scripts/DataTable/*.cs

运行时: DataTableComponent 加载 .bytes
        业务代码: GF.DataTable.GetDataTable<T>()
                var row = table.GetDataRow(id);
                int value = row.SomeField; // 强类型

特殊: 支持 A/B Test (命名: TableName#GroupName.xlsx)
```

### 2.2 Config (配置表)

```
输入: AAAGameData/Configs/*.xlsx
      (通常只有一个 GameConfig.xlsx)

处理: RefreshAllConfig()
      ├─ Excel2TxtFile() → .txt (Tab分隔)
      └─ ExportConfig2BytesFile() → .bytes (二进制)

输出:
      Assets/AAAGame/Config/*.txt
      Assets/AAAGame/Config/*.bytes

      (注意: 不生成 .cs 代码！)

运行时: ConfigComponent 加载 .bytes
        业务代码: GF.Config.GetString("Key")
                GF.Config.GetInt("Key")
                GF.Config.GetFloat("Key")
                (使用字符串 key 访问, 弱类型)

区别: 相比 DataTable:
      - 无 .cs 代码生成
      - 运行时弱类型访问
      - 适合简单键值对配置
```

### 2.3 Language (多语言表)

```
输入: AAAGameData/Languages/*.xlsx
      (如 ChineseSimplified.xlsx, English.xlsx)

处理: RefreshAllLanguage()
      └─ Excel 转 JSON → .json (不是 .txt/.bytes！)

输出:
      Assets/AAAGame/Language/*.json

      (注意: 使用 .json 格式, 不是 .txt/.bytes！)

运行时: LocalizationComponent 加载 .json
        业务代码: GF.Localization.GetString("Key")

特殊流程:
        1. PreloadProcedure 从 LanguagesTable (DataTable)
           获取当前语言对应的 AssetName
        2. 使用 AssetName 加载对应的 Language JSON 文件
        3. 业务代码通过 Key 获取多语言文本

区别: 相比 DataTable/Config:
      - 使用 .json 格式 (不是 .txt/.bytes)
      - 需要 LanguagesTable (DataTable) 管理语言映射
      - 支持运行时语言切换
```

### 2.4 对比总结

| 特性 | DataTable | Config | Language |
|-----|-----------|--------|----------|
| 目录 | DataTables/ | Configs/ | Languages/ |
| 输入 | .xlsx | .xlsx | .xlsx |
| 输出 .txt | ✅ | ✅ | ❌ |

## 三、框架工具链详解

### 3.1 核心工具类

| 类名 | 路径 | 作用 |
|-----|------|------|
| GameDataGenerator | ScriptsBuiltin/Editor/ | 统一的 Excel 导出入口 |
| DataTableGenerator | ScriptsBuiltin/Editor/DataTableGenerator/ | 数据表代码生成 |
| DataTableProcessor | ScriptsBuiltin/Editor/DataTableGenerator/ | 数据表解析处理 |
| AppConfigsInspector | ScriptsBuiltin/Editor/ | Unity Inspector 面板 |
| ConstEditor | ScriptsBuiltin/Editor/Common/ | 路径常量配置 |

### 3.2 导出流程详解

```
Unity Editor 点击 Export
    │
    ▼
GameDataGenerator.RefreshAllDataTable/Config/Language
    │
    ├─ 扫描 AAAGameData/DataTables/Config/Language 目录的 .xlsx
    │
    ├─ 根据 AppConfigs 中勾选的状态确定需要导出的文件
    │
    ▼
逐个处理每个 .xlsx
    │
    ├─ Excel2TxtFile()
    │   └─ 读取 Excel 第一个 Sheet
    │   └─ 按 Tab 分隔写入 .txt
    │
    ├─ GenerateDataFile() (DataTable only)
    │   └─ 解析数据类型
    │   └─ 生成二进制 .bytes
    │
    ├─ GenerateCodeFile() (DataTable only)
    │   └─ 读取代码模板
    │   └─ 生成 C# 行类型类
    │   └─ 写入 Scripts/DataTable/
    │
    └─ ExportConfig2BytesFile() (Config only)
        └─ 生成配置二进制 .bytes

输出目录:
    Assets/AAAGame/DataTable/  (.txt, .bytes)
    Assets/AAAGame/Scripts/DataTable/  (.cs)
    Assets/AAAGame/Config/  (.txt, .bytes)
    Assets/AAAGame/Language/  (.json)
```

## 四、总结

### 4.1 核心要点

1. **三层边界清晰**：
   - 外部数据层（本档不覆盖）
   - 适配层（本档不覆盖，但说明需要）
   - 框架原生层（本档详细描述）

2. **框架原生流程固定**：
   - 输入：必须是 `.xlsx`
   - 处理：必须通过 `GameDataGenerator`
   - 输出：`.txt/.bytes/.cs/.json`
   - 运行时：通过 GF 组件加载

3. **三类数据差异化处理**：
   - DataTable：最复杂（.txt + .bytes + .cs）
   - Config：中等（.txt + .bytes）
   - Language：最简单（.json）
